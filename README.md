# 🥗 Generator Pomysłów na Posty Dietetyczne

Aplikacja webowa pomagająca dietetykom w generowaniu pomysłów na posty, newslettery i inne treści związane z dietetyką.

## ✨ Funkcje

- **Trzy tryby pracy:**
  - **Tryb API** - bezpośrednia integracja z OpenAI API (wymaga klucza API)
  - **Tryb Prompt** - generuje gotowe prompty do skopiowania do darmowego chatu GPT
  - **Generuj Obrazy** - tworzy gotowe grafiki na social media (działa bez API!)

- **Elastyczne opcje:**
  - Różne typy treści (posty, newslettery, artykuły, reels)
  - Wybór grupy docelowej
  - Dostosowanie tonu wypowiedzi
  - Personalizacja tematyki

- **Generator grafik:**
  - Tworzenie grafik z tekstem (posty, story, bannery)
  - Różne rozmiary (Instagram post, Story, banner)
  - Wybór kolorystyki i stylu
  - Opcjonalna integracja z DALL-E do generowania tła
  - Pobieranie gotowych obrazów PNG

## 🚀 Jak używać

### Opcja 1: Bez klucza API (darmowy chat GPT)

1. Otwórz plik `index.html` w przeglądarce
2. Wybierz tryb "Tryb Prompt"
3. Wypełnij formularz (typ treści, temat, grupa docelowa, ton)
4. Kliknij "Generuj Prompt"
5. Skopiuj wygenerowany prompt
6. Wklej go do darmowego chatu GPT (np. chat.openai.com)
7. Użyj odpowiedzi GPT jako inspiracji do tworzenia treści

### Opcja 2: Z kluczem OpenAI API

1. Otwórz plik `index.html` w przeglądarce
2. Wybierz tryb "Tryb API"
3. Wprowadź swój klucz API OpenAI (klucz jest przechowywany tylko lokalnie)
4. Wypełnij formularz
5. Kliknij "Generuj Pomysły"
6. Otrzymasz gotowe pomysły bezpośrednio w aplikacji

## 💡 Wskazówki

- Klucz API jest przechowywany tylko w przeglądarce (localStorage)
- Możesz używać aplikacji bez klucza API - po prostu skopiuj prompt do darmowego chatu GPT
- Generator obrazów działa bez klucza API - tworzy profesjonalne grafiki z tekstem
- DALL-E (opcjonalnie) wymaga klucza API i generuje realistyczne tła
- Eksperymentuj z różnymi kombinacjami tematów i tonów
- Zapisz najlepsze pomysły i grafiki do późniejszego wykorzystania
- Pobrane grafiki możesz używać bezpośrednio na social media
